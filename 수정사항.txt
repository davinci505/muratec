*고객의뢰*

-새 의뢰 추가 페이지

1. 금액란 삭제

2. 네임 제품스펙->품번/제품스펙으로 변경 부탁드립니다.

3. 품번란 삭제

(견적 금액을 받기 전이라 의뢰 시점에서는 금액을 알 수 없습니다.)



*CCS견적*

1. 네임 CCS견적->견적관리로 변경 부탁드립니다.

-새 견적 추가 페이지

2. CCS 견적번호 뒤에 CCS 견적금액 추가 (CCS 견적금액란에 금액을 기입하면 ￥이 자동생성 될 수 있도록 부탁드립니다.)

3. BRT견적번호랑 BRT견적날짜 앞 뒤 순서 변경

4. 변경 후 BRT 견적번호 뒤에 BRT 견적금액 추가 (BRT 견적금액란에 금액을 기입하면 \이 자동생성 될 수 있도록
부탁드립니다.)

5. BRT 네고금액란 텍스트로 입력할 수 있도록 부탁드립니다.

6. 상태란 내용 수정 (상태란 내용 : 견적중, 재견적, 견적제출, 발주예정)

7. HMX발주번호, HMX발주날짜, CCS PO번호, CCS PO날짜 전부 삭제 (발주 진행된 부품들은 별도 페이지에서 관리가 필요해
보입니다.)



*견적부품*

1. 네임 견적부품->발주/납품관리로 변경 부탁드립니다.

-새 부품 추가 페이지

2. 네임 새 부품 추가->발주 부품 추가로 변경 부탁드립니다.

3. 네임 품번->CCS PO번호로 변경 부탁드립니다.

4. 네임 제품스펙->품번/제품스펙으로 변경 부탁드립니다.

5. 네임 시리얼넘버->작번/시리얼넘버로 변경 부탁드립니다.

6. 네임 견적수량->발주수량으로 변경 부탁드립니다.

7. Unitprice(BRT)->CCS PO금액으로 변경 부탁드립니다. (금액을 기입하면 ￥이 자동생성 될 수 있도록 부탁드립니다.)

8. Unitprice(HMX)->HMX발주번호로 변경 부탁드립니다. (텍스트로 기입할 수 있도록 부탁드립니다.)

9. HMX발주번호 뒤에 HMX발주금액 추가 부탁드립니다. (금액을 기입하면 \이 자동생성 될 수 있도록 부탁드립니다.)

10. 상태란 추가 부탁드립니다. (상태란 내용 : 발주중, 납품예정, 납품완료)

11. 납기란 추가 부탁드립니다.(텍스트 기입)
